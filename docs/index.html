    Como interpretar estes dados

    Um foco é uma detecção por satélite, não uma contagem de incêndios ou de área queimada. Diferentes satélites podem observar o mesmo evento.

    Últimos dias reúne registros operacionais de diferentes satélites. Histórico usa a série do satélite de referência para permitir comparações entre anos. Os totais das duas áreas não são diretamente comparáveis.

    Dias sem arquivo disponível aparecem como lacunas. O dia atual é parcial. Os intervalos recentes são contados a partir do horário atual, mesmo quando há atraso na fonte. As datas da interface usam o horário de Brasília (UTC−3).

    O mapa representa observações, não previsão ou simulação de propagação do fogo.
